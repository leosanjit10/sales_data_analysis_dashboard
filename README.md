# 📊 Sales Data Analysis Dashboard

## Project Overview

This project analyzes retail sales data to uncover key business insights related to revenue, customer segments, product performance, and regional sales trends.

The workflow included data cleaning, exploratory data analysis (EDA), KPI development, data visualization, and creation of an interactive Power BI dashboard.

---

## Business Questions

- Which region generates the highest sales revenue?
- Which product category performs best?
- How do sales change over time?
- What is the average shipping time?
- Which customer segment contributes the most revenue?

---

## KPIs

- Total Sales
- Average Sales per Order
- Top Performing Region
- Top Performing Category
- Average Shipping Days

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Excel
- Google Colab

---

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. KPI Calculation
5. Data Visualization
6. Business Insights & Recommendations
7. Power BI Dashboard Development

---

## Key Insights

- The West region generated the highest revenue.
- Technology was the top-performing category.
- Average shipping time was approximately 3.96 days.
- Certain customer segments contributed significantly more revenue than others.
- Sales showed strong growth patterns over time.

---

## Business Recommendations

- Increase investment in high-performing regions.
- Expand inventory for top-selling categories.
- Improve logistics to reduce shipping time.
- Focus marketing efforts on high-value customer segments.
- Monitor sales trends regularly for strategic planning.
